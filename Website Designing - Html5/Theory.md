
# HTML vs HTML5

## Question 1: Difference Between HTML & HTML5

| **Feature**                        | **HTML**                                      | **HTML5**                                                |
|------------------------------------|------------------------------------------------|-----------------------------------------------------------|
| **Version**                        | Older versions like HTML 4.01                 | Latest version of HTML                                    |
| **Doctype Declaration**            | Long and complex                              | Simple: `<!DOCTYPE html>`                                 |
| **Multimedia Support**             | No native support for audio/video             | Native `<audio>` and `<video>` tags supported             |
| **New Elements**                   | Limited semantic elements                     | Introduced semantic tags like `<header>`, `<footer>`, etc.|
| **Form Features**                  | Limited input types                           | New input types like `email`, `date`, `range`, etc.       |
| **APIs and Graphics**              | No built-in APIs                              | Supports Canvas, Web Storage, Geolocation, etc.           |
| **Browser Compatibility**          | Older browsers only                           | Modern browsers support it extensively                    |
| **Error Handling**                 | Less consistent                               | Improved error handling and parsing rules                 |

## Question 2: Additional Tags Introduced in HTML5

| **Tag**         | **Description**                                                                 |
|------------------|----------------------------------------------------------------------------------|
| `<header>`       | Defines the header section of a document or section                             |
| `<footer>`       | Defines the footer section                                                       |
| `<article>`      | Represents self-contained content like blog posts or news articles              |
| `<section>`      | Defines a section in the document                                                |
| `<nav>`          | Represents navigation links                                                      |
| `<aside>`        | Defines content aside from the main content (like sidebars)                     |
| `<figure>`       | Represents media like images with a caption                                     |
| `<figcaption>`   | Defines a caption for the `<figure>` element                                     |
| `<main>`         | Represents the main content area of a document                                   |
| `<mark>`         | Highlights or marks text                                                         |
| `<time>`         | Represents a specific time/date                                                  |
| `<progress>`     | Represents progress of a task                                                    |
| `<meter>`        | Displays a scalar measurement (like disk usage, fuel level)                     |
| `<canvas>`       | Used to draw graphics on the fly via JavaScript                                 |
| `<video>`        | Embeds video content                                                             |
| `<audio>`        | Embeds audio content                                                             |
| `<source>`       | Specifies multiple media resources for `<video>` or `<audio>`                   |
| `<track>`        | Specifies text tracks for media elements                                         |
| `<datalist>`     | Specifies a list of pre-defined options for input controls                       |
| `<output>`       | Represents the result of a calculation or user action                            |
| `<details>`      | Creates a widget for user to show/hide additional info                           |
| `<summary>`      | Defines a visible heading for the `<details>` element                            |
